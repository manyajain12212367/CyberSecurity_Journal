# 📘 CompTIA Security+ Journey

This section documents my learning journey through **CompTIA Security+**, a widely recognized, vendor-neutral certification that provides a strong foundation in cybersecurity fundamentals.

Security+ serves as my **starting point for structured certification preparation**, helping me build clarity across core security concepts and understand how they apply in real-world defensive scenarios.

---

## 🧭 Why Security+?

Security+ offers a comprehensive introduction to cybersecurity by covering:

* Fundamental security concepts and principles
* Common threats, vulnerabilities, and mitigation techniques
* Security architecture and operations
* Risk management and security governance

It establishes a solid baseline for deeper exploration into defensive security, malware analysis, and DFIR.

---

## 📚 Domains Covered

The Security+ curriculum is structured across the following domains:

1. **General Security Concepts**
2. **Threats, Vulnerabilities, and Mitigations**
3. **Security Architecture**
4. **Security Operations**
5. **Security Program Management and Oversight**

---

## 🧠 Learning Approach

* Emphasis on **understanding over memorization**
* Mapping concepts to real-world security scenarios
* Connecting fundamentals to defensive security practices
* Documenting progress, insights, and questions along the way
